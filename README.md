# 미라클 모닝 레벨업 · 둘이 함께 (v3.0)

둘이 같이 쓰는 아침 루틴 헌터 육성 앱. `index.html` 파일 하나로 동작합니다.

- 캐릭터 3종(냥이 · 댕댕이 · 토끼)과 6단계 등급 진화
- STR이 오르면 체형이 바뀌고(통통 모찌 → 살 빠짐), INT가 오르면 말투가 바뀝니다(단순 어휘 → 사자성어)
- **🐣 다마고치 돌봄**: 배고픔·행복도 게이지, 밥 주기 / 쓰다듬기, **🎮 12초 미니게임**(떨어지는 간식 받기, 최고 점수는 파트너와 공유)
- **💰 현물 자산**: 저축·현금을 기록하면 4단계 부자 등급(소박한 헌터 → 현물 재벌)에 따라 히어로 카드에 동전·금괴·왕관 오라가 붙습니다. 파트너에게 정확한 금액은 숨기고 등급만 공유하는 것이 기본값입니다.
- **🍀 재테크 퀘스트 + 재물운**: 경제 뉴스·무지출·가계부·저축 퀘스트 완료 시 1시간 재물운 버프(네잎클로버·금화·부자 명언)
- **⭐ 보너스 일일 퀘스트**: 매일 랜덤 2개 + 직접 추가. 기본 퀘스트까지 전부 깨면 **🏆 오늘의 올클리어** (+40 EXP, 파트너 카드에도 자랑 배지)
- 말풍선을 누르면 지금 상태에 맞는 새 대사로 바뀝니다(직전 대사 반복 없음).
- 일일 퀘스트 추가·체크·초기화, EXP·레벨·연속일, 진화 도감
- **초대 링크로 2인 파티**: 서로의 캐릭터·레벨·오늘 퀘스트·연속일·한마디·미니게임 최고점·부자 등급이 보이고, 🔄 지금 동기화 · 💌 응원 콕 찌르기가 됩니다.

## 저장 방식

- 내 기록은 항상 이 브라우저의 `localStorage`에 먼저 저장됩니다. 인터넷이 끊겨도 내 기록은 그대로입니다.
- 파트너와의 공유는 [jsonstorage.com](https://jsonstorage.com)의 익명 bin 두 개(내 것 · 방)로 이뤄집니다.
  서로 다른 bin에 각자 쓰기 때문에 덮어쓰기 충돌이 없고, 15초마다 상대 bin을 읽어 옵니다.
- 초대 링크에는 방 bin의 쓰기 키가 들어 있어, 링크를 받은 사람만 파티에 합류할 수 있습니다.
