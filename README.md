# 미라클 모닝 레벨업 · 둘이 함께 (v4.0)

둘이 같이 쓰는 아침 루틴 헌터 육성 앱. `index.html` 파일 하나로 동작합니다.

- 캐릭터 3종(냥이 · 댕댕이 · 토끼)과 **7단계 전직 진화** — E 하찮은(Lv.1) → D 갓 일어난 견습생(Lv.2) → C 동네 탐험가(Lv.4) → B 킹받는 기사(Lv.6) → A 다크 헌터(Lv.9) → S 그림자 군주(Lv.13) → **SS 국가권력급 신(Lv.18)**
- **초반은 쉽고 후반은 묵직한 EXP 곡선**: Lv.1→2 40 EXP(퀘스트 1~2개면 바로 첫 전직), 2→3 70 · 3→4 110 · 4→5 160 · 5→6 220 · 6→7 300 · 7→8 400 · 8→9 520 · 9→10 660 · 10→11 820 · 11→12 1000 · 12→13 1200 · 13→14 1450 · 14→15 1750 · 15→16 2100 · 16→17 2500 · 17→18 3000 (최대 Lv.18, 합계 16,300 EXP)
- **진화 도감 7칸**: 전직할 때마다 새 모습이 해금되고, 지금 단계는 금빛 테두리로 표시됩니다. 3종 × 7단계 × 통통/슬림 = 42장 일러스트가 모두 HTML 안에 들어 있습니다.
- STR이 오르면 체형이 바뀌고(통통 모찌 → 살 빠짐), INT가 오르면 말투가 바뀝니다(단순 어휘 → 사자성어). 체형은 7단계 전부 슬림 버전이 따로 있습니다.
- **🐣 다마고치 돌봄**: 배고픔·행복도 게이지, 밥 주기 / 쓰다듬기, **🎮 12초 미니게임**(떨어지는 간식 받기, 최고 점수는 파트너와 공유)
- **💰 현물 자산**: 저축·현금을 기록하면 4단계 부자 등급(소박한 헌터 → 현물 재벌)에 따라 히어로 카드에 동전·금괴·왕관 오라가 붙습니다. 파트너에게 정확한 금액은 숨기고 등급만 공유하는 것이 기본값입니다.
- **🍀 재테크 퀘스트 + 재물운**: 경제 뉴스·무지출·가계부·저축 퀘스트 완료 시 1시간 재물운 버프(네잎클로버·금화·부자 명언)
- **⭐ 보너스 일일 퀘스트**: 매일 랜덤 2개 + 직접 추가. 기본 퀘스트까지 전부 깨면 **🏆 오늘의 올클리어** (+40 EXP, 파트너 카드에도 자랑 배지)
- 말풍선을 누르면 지금 상태에 맞는 새 대사로 바뀝니다(직전 대사 반복 없음).
- 일일 퀘스트 추가·체크·초기화, EXP·레벨·연속일
- **초대 링크로 2인 파티**: 서로의 캐릭터·전직 단계·레벨·오늘 퀘스트·연속일·한마디·미니게임 최고점·부자 등급이 보이고, 🔄 지금 동기화 · 💌 응원 콕 찌르기가 됩니다.

## 저장 방식

- 내 기록은 항상 이 브라우저의 `localStorage`에 먼저 저장됩니다. 인터넷이 끊겨도 내 기록은 그대로입니다.
- 예전(v3.0)에 쌓은 EXP는 그대로 이어집니다. 같은 `totalExp` 값이 새 7단계 곡선에 다시 맞춰지므로, 예전 Lv.10(S) 사용자는 새 곡선에서 Lv.9(A)로 보이고 S급(Lv.13)까지 다시 3,680 EXP가 필요합니다.
- 파트너와의 공유는 [jsonstorage.com](https://jsonstorage.com)의 익명 bin 두 개(내 것 · 방)로 이뤄집니다.
  서로 다른 bin에 각자 쓰기 때문에 덮어쓰기 충돌이 없고, 15초마다 상대 bin을 읽어 옵니다.
- 초대 링크에는 방 bin의 쓰기 키가 들어 있어, 링크를 받은 사람만 파티에 합류할 수 있습니다.

## 홈 화면에 추가 / 앱 설치 (PWA)

안드로이드 크롬·iOS 사파리에서 **홈 화면에 추가**로 설치하면 주소창 없는 `standalone` 앱처럼 열립니다.

- `manifest.webmanifest` — 이름 `나혼렙 미라클 모닝` / 짧은 이름 `미라클모닝`, `start_url`·`scope` `./`, `display` `standalone`, 테마 `#8B5CF6`, 배경 `#FDF8F3`
- 아이콘 — `icon-192.png` · `icon-512.png` (any), `icon-maskable-192.png` · `icon-maskable-512.png` (maskable, 안전 영역 확보), `apple-touch-icon.png` 180×180
- `sw.js` — 서비스 워커. 앱 파일은 **network-first**(새 버전 배포 시 항상 최신판), `jsonstorage.com` 등 **외부 API는 캐시하지 않고 네트워크로 통과**, 오프라인일 때만 캐시본으로 실행
